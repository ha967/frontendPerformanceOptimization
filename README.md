# 前端性能优化

基于 React + TypeScript + Vite 的前端性能优化实践项目。

## 技术栈

- React 19
- TypeScript 6
- Vite 8
- Oxlint

## 快速开始

```bash
npm install
npm run dev
```

## 脚本

| 命令              | 说明                     |
| ----------------- | ------------------------ |
| `npm run dev`     | 启动开发服务器           |
| `npm run build`   | 类型检查并构建生产产物   |
| `npm run preview` | 预览生产构建             |
| `npm run lint`    | 运行 Oxlint 代码检查     |

## 目录结构

```
├── public/          # 静态资源
├── src/
│   ├── App.tsx      # 根组件（占位）
│   ├── main.tsx     # 应用入口
│   └── index.css    # 全局样式
├── index.html
├── vite.config.ts
└── tsconfig*.json
```
